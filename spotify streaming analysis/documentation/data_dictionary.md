# Data Dictionary

| Field | Description |
|---|---|
| Artist Name | Artist or group name |
| Sex | Sex classification provided by the source |
| Country of Origin | Artist's country of origin |
| Primary Language | Primary language associated with the artist |
| Primary Genre | Primary genre |
| Artist Type | Solo artist or group |
| Debut Year | Year of debut |
| Total Streams (Millions) | Total streams, expressed in millions |
| Lead Streams (Millions) | Lead-artist streams, expressed in millions |
| Feature Streams (Millions) | Feature/collaboration streams, expressed in millions |
| Solo Streams (Millions) | Solo streams, expressed in millions |
| Solo Stream % | Percentage of total streams classified as solo |
| Collaborative Streams (Millions) | Collaborative streams, expressed in millions |
| Collaborative Stream % | Percentage of total streams classified as collaborative |
